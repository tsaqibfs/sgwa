# SGWA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Menghasilkan demo web layanan publik dengan klasifikasi ML, MySQL, dan alur warga-staf-admin yang dapat diuji.

**Architecture:** Modular monolith FastAPI menyediakan API untuk React/Vite. SQLAlchemy dan Alembic mengelola MySQL. Pipeline scikit-learn dilatih lokal dan dimuat sekali saat startup; service workflow mengendalikan transaksi dan hak akses.

**Tech Stack:** Python 3.11+, FastAPI, SQLAlchemy 2, Alembic, PyMySQL, PyJWT, Argon2, scikit-learn; MySQL 8.4; React, TypeScript, Vite, React Router, Radix Themes, Phosphor; Pytest, Vitest, Testing Library, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-04-sgwa-design.md`

**Status:** Rencana siap untuk review pengguna. Metode eksekusi telah dipilih: langsung dalam sesi melalui executing-plans. Implementasi belum dimulai.

## Global Constraints

- Python 3.11+; SQLAlchemy 2; MySQL 8.4; tidak memakai SQLite sebagai pengganti termasuk pada pengujian integrasi.
- Prefix `/api/v1`.
- Registrasi selalu membuat role citizen. Token akses JWT berumur 30 menit, disimpan dalam cookie HttpOnly SameSite=Lax.
- Request mutasi memakai token CSRF dan pemeriksaan Origin.
- Judul 5-150 karakter, deskripsi 20-5000 karakter setelah trim.
- Daftar menggunakan page >= 1 dan page_size 1-100.
- Pipeline awal: TF-IDF word unigram/bigram dan Logistic Regression, random_state 42.
- Dataset awal: minimal 200 contoh sintetis berbahasa Indonesia, minimal 50 per kelas, dengan label dan group_id untuk keluarga skenario/parafrasa.
- Pisahkan train/test 80:20 berdasarkan group_id sebelum fit vectorizer; kelompok parafrasa tidak boleh tersebar di kedua bagian.
- Confidence < 0,60, teks tanpa fitur dikenal, atau dinas tujuan tidak aktif menghasilkan escalated dan belum ditugaskan.
- Code dinas tidak dapat diubah setelah dibuat. Penambahan dinas tidak mengubah prediksi historis.
- Semua waktu disimpan dalam UTC dan ditampilkan sebagai Asia/Jakarta.
- Tidak ada approval otomatis oleh AI. AI membantu routing, sedangkan staf/admin membuat keputusan layanan.
- Layout diuji pada lebar 375, 768, dan 1366 piksel; tidak ada scroll horizontal seluruh halaman.
- Tidak ada nilai metrik evaluasi atau hasil tes yang diklaim sebelum dijalankan.

## Review Focus

1. Dinas baru/kelas model baru: reroute manual langsung tersedia; probabilitas dan UI tidak terikat empat kelas awal (Task 3, Task 5).
2. Teks tidak dikenal dan model hilang: eskalasi yang jujur atau 503 tanpa data setengah jadi (Task 3, Task 4).
3. Dua staf mengubah permohonan bersamaan: tepat satu update berhasil dan lainnya 409 (Task 4).
4. Sesi kedaluwarsa dan CSRF salah: tidak ada perubahan database; pengguna dapat login ulang dan mempertahankan input (Task 2, Task 6).
5. Dinas dinonaktifkan dan data historis: riwayat tetap terbaca; routing baru tidak diarahkan ke dinas nonaktif (Task 4, Task 5).

**Interfaces:** Consumes `get_session`, `User`, `Settings`. ### Task 3: Dataset, training, dan inference ML

**Files:** Create `ml/__init__.py`, `ml/data/requests.csv`, `ml/train.py`, `ml/tests/test_training.py`, `backend/app/ml/{classifier,schemas}.py`, `backend/tests/test_classifier.py`, `docs/ml.md`.

**Interfaces:** Produces `train(dataset_path: Path, output_dir: Path) -> dict`, `Classifier.predict(text: str) -> Prediction`, `Classifier.metadata() -> dict`. Prediction: `agency_code: str`, `probabilities: dict[str,float]`, `confidence: float`, `known_features: bool`, `model_version: str`. Missing/corrupt artifacts raise `ModelUnavailable`. Artefak: model.joblib, metadata.json, evaluation.json, train.csv, test.csv. API process memuat model sekali; hanya artefak lokal hasil training proyek yang dipercaya.

- [ ] Tulis tests split tanpa group overlap; semua kelas muncul dalam kedua split; dataset minimal 200/50 per kelas; reproducible metrics dengan random_state 42; `predict` memberi probabilitas berjumlah 1; teks tanpa vocab `known_features == False`; missing artifact raises ModelUnavailable. Tambahkan test training dengan kelas kelima `pendidikan` yang muncul pada hasil probabilitas.
- [ ] Jalankan `python -m pytest ml/tests backend/tests/test_classifier.py -v`; Expected: gagal karena training/classifier belum ada.
- [ ] Buat dataset sintetis dengan kelompok skenario dan label yang diperiksa manual. Bagi tepat 20% kelompok tiap kelas sebagai test dengan seed 42; TF-IDF fit hanya pada train. Implementasikan LogisticRegression, laporan metrik, hashes, dan validasi konsistensi metadata/model.
- [ ] Jalankan `python -m ml.train --dataset ml/data/requests.csv --output ml/artifacts`, lalu test di atas; Expected: artefak nyata dan test lulus. Laporkan macro-F1 aktual; jangan mengubah test set agar target terlihat tercapai.
